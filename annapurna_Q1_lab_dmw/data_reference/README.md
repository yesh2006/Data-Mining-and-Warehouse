# Input data used

The exam work was executed against these instructor-provided inputs:

- `sales/` — 4,457 daily sales export files (the supplied archive contained CSV files; loader also supports Parquet).
- `masters.sql` — PostgreSQL master data: stores, products, product categories, price revisions.
- `finance_monthly.csv` — 12 signed-off finance monthly revenue values.
- `billing_notes.md` — RetailEdge POS vendor handover rules.
- `truth.json` — supplied ground-truth metadata/results (kept out of this GitHub pack).

The raw sales archive and ground-truth file are intentionally not included in this GitHub pack. Add them only if the instructor permits redistribution.
