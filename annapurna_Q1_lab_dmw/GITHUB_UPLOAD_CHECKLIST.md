# GitHub upload checklist

Before pushing:

- [ ] Keep `raw/`, `sales.zip`, `truth.json` and local database files out of the repository.
- [ ] Do not commit `.env` or any password/secret.
- [ ] Use `.env.example` for the local configuration template.
- [ ] Check screenshots for any credentials before making the repository public.
- [ ] Update the README name/author details if required by the instructor.
- [ ] Add your final report if the instructor requires a PDF.
